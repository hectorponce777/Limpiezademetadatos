# Sin rastro para Hosting web de Hostinger

Este paquete contiene la aplicación estática para limpiar PDF, DOCX, JPG y PNG en el navegador, sin subir los archivos y sin necesitar Python ni VPS en el hosting.

Descarga `sin-rastro-hostinger-web.zip` usando el botón de descarga del archivo en GitHub. El ZIP pesa aproximadamente 2,8 MiB.

1. En hPanel crea una carpeta nueva, por ejemplo `public_html/limpiar`, para conservar tu web actual.
2. Sube el ZIP y extráelo. `index.html` debe quedar directamente dentro de esa carpeta junto a los scripts y `vendor/`.
3. Activa HTTPS y abre la carpeta `/limpiar/` en tu dominio.
4. Lee `LEEME-HOSTINGER.txt` antes de utilizar la aplicación; incluye límites y licencias.

La versión se probó con 26 casos de navegador y 13 descargas verificadas con bibliotecas independientes. El hosting de destino aún debe comprobarse después de subir los archivos.
